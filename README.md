## About The Project

<!--[![Product Name Screen Shot][product-screenshot]](https://example.com) -->


This website is used to showcase my art commissions (pricing and workflow) alongside my personal programming projects. It brings together my creative and technical skills into a single portfolio.

The website includes:
* An About section introducing who I am, with links to my professional and creative platforms (Instagram, LinkedIn, GitHub).
* A Commissions section detailing pricing and what is included in each offer.
* A Projects section highlighting my personal coding work, the programming languages I use, and the tools I work with. It features my first website, a fan page inspired by the anime Hell Girl (also known as Jigoku Shōjo), as well as my first visual novel, Project Aiko, developed in Ren’Py and currently in progress.
* A Characters section presenting original character designs with descriptions, implemented using a JavaScript carousel.
* An Extras section that includes an interactive drawing canvas. Submitted drawings are sent to a backend API and stored globally using MongoDB. Some Spotify playlists are also showcased to display my music taste as it is a huge part of my online presence.
* A FAQ section answering common questions.

In addition, the website also contains a few interactive easter eggs, such as a clickable star in the right corner of the header with sound effects and my favorite quote linked, a fake search feature that displays a playful message if the user tries to enter something, and subtle UI sound effects with animated social links.

Use the `BLANK_README.md` to get started.
